# OSCMidi UI Implementation Plan

**Goal:** Donner une identité de régie à OSCMidi et rendre les connexions plus faciles à comprendre.

**Architecture:** Conserver React, Tauri, Radix, Lucide et les données existantes. Centraliser les couleurs sémantiques et les surfaces ; modifier la coque, puis le dashboard. Aucune modification du moteur natif.

**Spec:** [2026-10-15-ui-design.md](../specs/2026-10-15-ui-design.md)

## Contraintes

Windows, FR/EN, trois palettes, aucune dépendance ajoutée. Configuration et activité réelle sont distinctes. Les préférences existantes restent compatibles. Exécution dans cette session ; pas de commit ou de publication demandé.

## Points de revue

Bridge arrêté avec RTP actif ; sorties configurées mais désactivées ; valeurs inconnues ; noms longs ; zoom et clavier. Les tests fonctionnels couvrent les états du trajet du signal. Le navigateur couvre le rendu, la taille et les interactions.
